# TriQuil-Hackathon-2026-September-15
TriQuil is a wearable relaxation device from Auvara Wellness Inc. It uses three vibration actuators on the "TriQuil Triangle" (P6, LU9, H7) to create spatial relaxation patterns, with an AI layer for personalized coaching. The free plan is fully usable. A second product, PulseCore, brings the concept to electrical stimulation.
